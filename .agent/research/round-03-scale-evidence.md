3. **现有地图足够提供 ≥3 个非共线匹配候选，但并未完成官方示意图的精度合格配准。** 迎西的南门、主楼、机械馆、图书馆、体育馆可匹配；虎峪的图书馆、八角训练馆、田径场可匹配，再以北部主楼核验。更省工且可靠的主线是直接使用 OSM footprint 的米制坐标；官方图只核名称、拓扑和缺失区域，不把旧示意图整图拉伸当实测。

## 可复现的米制建模方法

1. 复用已下载数据，不把免费公共 API 变成游戏运行时后端。需要重取时，只执行 `tyut-overpass-query.txt` 的同一有界查询，端点 `https://overpass-api.de/api/interpreter`，HTTP GET 的 `data` 参数 URL 编码；用真实应用名的 User-Agent，遇 429/权限拒绝立即停止，不轮换服务器/身份绕过限制。
2. 本轮局部原点：虎峪 `(lon0=112.5165934, lat0=37.8526095)`；迎西 `(112.5162083, 37.86119865)`。二者只是方便渲染的小数值原点，不是已核实“校门”或“学校中心”。如需同一城市连续坐标，应改用同一个原点并保留两个校区的真实偏移。
3. WGS84 椭球 `a=6378137 m`，`e²=0.0066943799901413165`。经纬度转弧度；取 `N=a/sqrt(1-e²sin²φ)`，`ECEF=(Ncosφcosλ, Ncosφsinλ, N(1-e²)sinφ)`，本轮高度假设为 0。减原点 ECEF 得 `dx,dy,dz`，再取 `E=-sinλ0 dx+cosλ0 dy`；`North=-sinφ0 cosλ0 dx-sinφ0 sinλ0 dy+cosφ0 dz`。Three.js 可用 `(x=E, y=height, z=-North)`。
4. 将 footprint 的每一个顶点转换，不只搬质心/包围盒。校界、建筑、球场使用同一变换，保持统一米尺；不能分别为了构图缩放每栋楼。采用同一套色板、材质、照明与真实比例镜头获得审美，而非牺牲比例。
5. 本轮面积用 ENU 二维 shoelace、质心用面积加权公式计算。GeoJSON 的经纬度质心以局部去原点的度坐标 shoelace 计算；足够作为对象标签位置，不是测量控制点精度声明。输入坐标七位小数是数据存储精度，不是其地面准确度。
6. 本次只获得水平几何。垂直挤出若用“层数 × 假设层高”必须单独存 `estimated_height_m`、`assumed_floor_height_m` 与标签，不覆盖 `height_m` 源值；地形、屋顶结构、立面、门架跨度/净高没有由 footprint 自动得到。
