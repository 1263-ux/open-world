## 3. 真实比例门：不能把任意size改成“米”就算完成

- 空间负责人另交 `.agent/research/round-03-scale-evidence.md`。本任务已读取其原始`inputs/tyut-overpass-campus.json`，确认130个对象：虎峪边界way427605255为7个闭合坐标（6个不同顶点）；虎峪图书馆689323088、中区主楼689323083、矿机楼689323084，以及迎西主楼182055472、机械馆182055474、图书馆182055475、清泽园343238097均有geometry。**直接以这些真实轮廓/路网建立米制校园，不再保留任意70m岛。** 主控报告虎峪约670×430m及另核的版本日期，本任务未复算范围；此JSON没有对象timestamp，不能冒充携带版本元数据。校园边界不自动证明各楼高度；完整名称/年代/道路与许可仍以资料负责人核验为准。
- 每区统一局部坐标：`1 unit=1m`、+Y上、+X东、-Z北。WGS84节点统一投影到局部米制，所有楼、路、地界用同一变换，禁止X/Z非等比拉伸或把两校区缩成一样大。多边形须≥3个不同非共线点；保留source URL、对象/版本（缺则记未知）、日期、CRS/变换、点数、置信度、误差及署名。原始包含78条highway且无footway，也包含校外266m高楼：先按两区边界/对象身份裁选，校内可走支路另核，不能把包内所有道路当步行路。OSM不是测绘精度保证；必须保留©OpenStreetMap contributors及ODbL说明，衍生数据集的许可/提供义务由资料负责人核对后落实。
- 建筑占地需有效轮廓/控制距离；高度优先明确height标签/独立证据，`building:levels`不是米数（原始数据有13/6/5等层数标签，无据不得套统一层高称实测）。不用地界跨度、单张透视照或楼层猜值冒充。对照可核控制长度，报告模型差值及来源误差；不预设“已达5%实测精度”。高度未知就明确估计/缺口。**地面有尺度但高度缺证据=部分实尺度，不能验收为完整真实比例版。**
- 尺度待补时先做UI/相机/有来源的轮廓，不能继续量产假尺寸地标。关键缺口一次性具体到建筑/量项，必要时向用户索取获授权图纸/测量资料；不无限搜索拖延。

## 4. 可直接实施的视觉规格

**布局**：桌面顶部56–64px；下方场景近满屏，只有一个可收起248–280px右面板，目录/详情/任务共用，1440px下场景可见宽≥75%。删大标题与英文装饰栏。手机390×844：顶部约56px、场景占剩余视区、底部64–80px当前步骤条；目录/资料按需底部抽屉，不常驻在地图下方。首次开始不长滚动；触控≥44px。

**相机**：保留斜俯视可逆默认，高于地平线约35–42°；虎峪从北门外看向内部，门架位于前景下三分之一，路线延伸到中景，两楼形成层次；迎西另设入口镜头。按已建模路线包围盒适配，不沿用固定86/手机110视域；主体包络目标占画布75–90%宽、65–85%高。只调镜头，不改建筑比例。提供全区/当前目标/复位；拖拽打断跟随，限制沉地/迷失；减弱动态偏好时直接到位。

**模型**：北门用独立连续弧带截面挤出，横牌/支撑/侧体分mesh，不弯成玩具管；梅花用中央入口+折翼独立体块、薄平檐与窗组横向节奏。正面/斜俯视/侧面三镜头对照来源。图书馆、迎西南侧入口/办公楼/机械馆/清泽园逐项补轮廓与尺度，不能共用同一屋顶。背景楼按可核占地/高度层级，禁止随机房子填图。

**地表**：删漂浮圆角米色岛，改连续校园地面：沥青主路、浅灰步道、入口硬铺装、成片草地，路缘/绿篱收边。路径接实际入口并绕楼，不连接建筑中心/穿楼。树沿路成行、庭院成组，取消无目的撒36棵圆锥树；原创两类阔叶冠与受控色差。未知景观只放中性绿地，不编造景点/安防细节。

**美术设计值，非实测色号**：墙`#D8D1BD`、门架`#B9BDB7`、玻璃`#405B5F`、路`#727875`、铺装`#CDCBC0`、草`#A8B78D`、树`#567250/#7E9360`、UI深绿`#233F37`。红褐仅门牌/可信细节，任务金`#D6A34D`少量点睛。柔和日光+天空补光+接触阴影；避免过曝洗白。先做好接地、檐口/窗洞深浅和粗糙度，不先加昂贵后处理。选中用细描边/编号，删吞建筑的大圆环；来源/误差放详情，不铺在画面中央。

## 5. 连贯玩法：不再依次点三张卡

`选校区 → 门口开始 → 下一站线索 → 沿室外路径移动 → 入口到站 → 观察题/记录 → 下一站 → 完成纪念页 → 重玩/退出`。

首个可逆实现：**脚步标记沿路网折线连续移动**，点路径设目标，桌面/手机一致；相机跟随/自由切换，不瞬移选楼。不做骨骼/全世界碰撞/大型导航系统，复用路线数据、现有quest/storage；按已定义连通路径遍历即可。当前只高亮一站，入口邻近开放记录；观察题只问可见轮廓，不编造历史。错序提示不清零。速度/到站阈值是游戏参数，与测量数据分开。

开始/到达/完成均有短反馈，完成页展示路线与收集卡；双区进度独立，切区说明进行中任务处理，刷新恢复。迎西从南侧入口沿楼侧室外路至办公楼/清泽园，不能穿办公楼。真实通行性未核不称现实导航。WebGL失败有等价列表任务并标明降级，不假装完成空间到站测试。
