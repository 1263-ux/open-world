# 校园漫游品质切片 · 设计

更新：2026-10-30 UTC。`C2 + R-ui + R-runtime + R-architecture + A3`。

## G0 / Goal

- **Product core：** 横屏、真实可操控的第三人称太理校园游戏；用连续步行、可信人尺度、可辨认建筑和完整玩法形成校园感。
- **Primary user：** 校园访客、学生与校友；从机械馆步行到清泽园，观察、互动、进入原版古建守护并回到当前位置。
- **Role ownership：** Agent 自主调研、实施、试玩、验收、参考比较与常规纠错；用户只做重大成果验证。主控集成/发布，专业 Agent 按文件所有权工作。
- **Non-goals：** 本轮不做后端、账号、多人、室内/BIM、测绘级导航、新地图平台、通用引擎，也不一次精修双校区所有建筑。
- **Forbidden claims：** 自动路线移动≠真实角色控制；米制占地≠实测楼高；DOM/截图≠玩法验证；未玩到参考≠已试玩；旧 Hks/删减替代版≠完整上游；候选构建≠现网升级；模拟手机≠真机。

## 已确认约束

1. 用户授权自行完成验收、与给定参考比较、持续做出独特且优美的成品；不再将“地图还是角色”“是否公开”“Hks 是否用户项目”列成待确认。
2. `1263-ux/open-world/main` 可在适用检查后直推。现有公开站点可升级，但候选未验证前保持现网；范围不含新付费/扩权限/无关站点。
3. 首先形成迎西 **机械馆→清泽园** 连续样板；既有米制占地、数据来源、地标/存档 ID 不随美术便利任意变形。
4. Hks 目标 `ShanEior/Hks main@7199cae`，解析完整 SHA 后固定；原生 **1280×720 / 420 秒**。完整保留核心源码、技能/敌人/Boss/教学/美术/流程，以小的可审查补丁适配校园嵌入，不再沿用旧竖屏/300 秒内容。
5. 复用当前 Vue 3.5.44、Three 0.186.1、GLTFLoader/OrbitControls、Phaser 3.90 和既有数据/GLB/测试能力，不另造引擎。

## 设计选择：暖晴工科校园

### 视觉层级与色板

- 温暖石材 `#e4d5ba`、旧砖 `#a9684f`、灰绿 `#6e8861`、松绿 `#314c46`、晴空 `#b7d5de`、少量暖金 `#dcb568`；UI 米白 `#f5f2e8` 与深绿文字。
- 晴朗柔日光 + 稍冷天光填充；保留檐下、树下层次。避免统一褐黄覆盖、浓雾隐藏细节、过曝白墙、发黑阴影和过强塑料高光。
- 建筑轮廓优先：机械馆钟楼/长翼/檐口仍是主角。中景树群有高低疏密；近景以路缘、铺装变化、草边、少量椅灯/路标建立尺度，不用密集同型球树遮立面。
- 人物约 **1.7 m** 作为设计标尺，近景第三人称镜头建议距角色 5–7 m、肩上略俯，需实际调试；建筑不为容纳镜头缩成玩具。步行/跑速以 m/s 计并记录，不用夸张速度掩盖路线设计。

### 连续样板的三个空间节拍

1. **机械馆前：** 能同时读出钟楼、长翼和人物，真实占地不改；可步行观察正/斜面，入口用铺装和路缘组织，不制造未经核实的可进入室内。
2. **林荫连接段：** 路面、草缘、树冠与人行空间连成一体；保证直线步行/绕障/转向可读，不出现模型孤岛、空白地板或穿墙捷径。
3. **清泽园展开：** 园林绿地与建筑形成开合，终点有可读地标/交互提示。设计性绿化/装饰明确不是现场测绘复原；未经来源核实不添加真实历史事实。

### 操控与 UI

- 默认第三人称：WASD/方向键移动，镜头转动相对角色运动；停止即停，失焦清键；触屏左移动、右转向，各自可同时使用。跑步/跳跃若实现必须实际测且不能穿越边界/建筑。
- 路线只作视觉引导，到达由人物实际位置判定；点击“前往”不能替玩家自动完成步行。若需辅助模式必须明确标签，不冒充默认旅程。
- 地图是辅助视图，有清晰“返回角色”操作，切换不丢位置、朝向、任务；单击信息、移动拖拽与镜头输入互不误触。
- 游戏画面优先；桌面边栏可收起，不长期遮角色/钟楼/路线；手机以横屏为主要游戏体验。竖屏提示旋转/保持可返回，不能把 Hks 逻辑画布改成竖屏。
- Hks 同源懒加载 iframe。Phaser `FIT` 保持 16:9，可留边，不用 `RESIZE` 偷改原生逻辑尺寸。任何失败都可返回校园；退出回收声音/输入/计时，恢复人物与任务。

| ID | 必须建立的结果 | 需要的证据 / 失败条件 |

| C2 | 人物真实受控移动/转向/停止 | 浏览器真实键鼠，前后/左右/镜头后再前进，实际位置变化；失焦/keyup 后停，无自动路线代走 |
| C3 | 机械馆→清泽园连续可走 | 一次连续真实输入录像/trace与到达事件；不 teleport、不写状态、不越墙；沿途三个空间节拍截图 |
| C4 | 碰撞与镜头稳定 | 正面/斜向贴墙、拐角、校园边界、近建筑镜头；不进楼体/地下，不出现持续遮挡或大跳变 |
| C5 | 横屏手机可用 | hasTouch 实际触摸输入，左移右转同用、停止、信息/返回可点；844×390 或类似横屏无裁切；模拟/真机标明 |
| C6 | 独特暖清风格统一 | 同一构建机械馆、连接段、清泽园三张无 UI/含 UI 图；角色/立面/树冠/铺装/天空层次与尺度对照；不是只交局部漂亮特写 |
| C7 | 数据与旧功能不回退 | 米制占地/地标ID/任务存档检查；双校区切换、地图往返、信息、任务重玩/退出与刷新回归 |
| H1 | 完整固定上游 Hks | 完整 SHA、文件/资产清单、原始 hash 与适配 diff；1280×720/420s 常量与运行只读值相符，无核心内容删减 |
| H2 | Hks 真正可玩且校园不丢状态 | 菜单→教程→真实移动/战斗/升级→自然结算→重玩→退出→重入；原版后期/Boss/胜利未自然到达则明确缺口，不能作弊制造 PASS |
| H3 | 原生横屏不裁切 | 桌面1280×720逻辑画布与手机横屏 FIT；科普/升级/结算文字、返回控制可读，无意外竖屏适配 |
| R1 | 异常路径安全 | WebGL/GLB/iframe 失败可解释且可恢复/返回；重复切校区/退出重入无额外音频/输入、无未处理错误 |
| P1 | 性能有实际边界 | 记录设备/浏览器/网络/视口/构建、冷启动、样板路线 FPS/资源/绘制数；30 FPS/5s 为目标，未测不宣称达成 |
| D1 | 授权部署可追溯可回滚 | 适用静态/单元/E2E + fresh review、远端/CI、候选/现网同身份、公开资源健康、上版可恢复 |

## 本轮有界资料调研（计划前，2026-10-30 UTC）

- [Three.js OrbitControls 官方文档](https://threejs.org/docs/pages/OrbitControls.html)：轨道旋转/缩放/平移、阻尼更新；继续复用辅助地图，不将它当角色控制器。已读取；本地锁定 Three 0.186.1，具体 API 仍以本地源码为准。
- [Phaser Scale Manager 官方文档](https://docs.phaser.io/phaser/concepts/scale-manager)：`FIT` 保持比例，`RESIZE` 变更逻辑可视区；采用原生1280×720 + FIT。已读取；当前 Hks 依赖版本以集成者锁文件复核。
- [参考原始 URL](https://jluai.bitmiracle.cn/campus/?qq_aio_chat_type=3) / [此前观察的重定向目标](https://jlu.online/)：本轮 web 打开均不可访问；Firecrawl 单次 live fetch 返回 `ERR_TUNNEL_CONNECTION_FAILED`，未取得新内容。此前主控浏览器已观察地图/信息/天气/视图设置 DOM，但 WebGL 不可用；不推导任何已验证移动/碰撞/性能。
- 已重读三份完整原计划、AGENTS、历史 decisions/progress 与现有场景/UI/Hks 源码。当前多 Agent 正在写实现，源码观察只描述快照，不替代最终构建验证。

## 参考比较方法与回滚

按入口/信息、校园辨识度、尺度/连续步行、镜头、环境艺术、玩法、性能/触屏逐项填“参考证据 / 本作证据 / 差距 / 下个改进”。参考尚未知的项保留 unknown，不打虚构分数，不声称“已全面超过”。本轮先落实自己的独特暖晴校园与真实操控优势，再根据可取得的实证比较推进。
