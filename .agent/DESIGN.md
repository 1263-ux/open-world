# 设计现状与品质缺口

更新：2026-11-03。虎峪、迎西已完成局部精修技术验收，新增可切换原创阅读庭院/照片手记驿站。它仍是低模体验版，不是全校园豪华重建，也不能声称用户已满意。

## 当前产品形态
第三人称、横屏优先、双校区示意探索。迎西主线通过摄影、有限垂直空间与纸飞机连接；Hks 为可选独立支线，不计入手记完成。不是 BIM、现实导航、全楼室内或高品质校园复原。

## 已实施的技术约束
Vue 管理 UI/状态，Three 使用单 renderer/RAF，Phaser Hks 通过 iframe 隔离。现有角色碰撞、互斥活动模式、飞行冻结/完整姿态恢复和有限连续碰撞保留。摄影要求距离、构图、遮挡、模型准备及相机稳定，高台另要求高度；不得以放宽判定伪造成功。

## 美术现状
本轮两模式共享双冠变体、有限立面与花床精修；理想模式追加原 bounds 内的木石凉廊、座椅/植栽/阅读台与照片展示台。真实近桌距离/视线检查后复用校园介绍和会话相册，不新增任务存档。单 renderer/RAF、模式独立碰撞快照、共有地面切换与失败回滚保持。

大面积场景仍为低细节体块。原创低台采用象牙石压顶/踏面与灰绿实心护墙表面，保持原碰撞轮廓；这是局部收尾，不代表全校园已具备成熟美术品质。纸飞机与门标记可辨认，但简化造型和界面密度仍需质量诊断。

本轮精修未调用 Astra/API。历史已有设施中，确认由 Astra API 生成并接入的是折纸站；平台最终表面为本地实现，不是 Astra 新平台。后续平台请求在计数阶段没有确认收据，结果/计费未知，已停止，未取得新生成产物，不推定零费用。历史其他开发调用与模型作者记录仍保留在归档，不据此扩大本轮 Astra 成果。网站运行不需要 API key。

## 未达标或未验证
- 校园大部分仍是低细节体块，场景质感、角色/镜头与界面整体品质未达到用户期待；通过功能测试不证明美术或游玩体验优秀。
- 横屏完成面板与背景跑跳控件存在叠压/低对比。CI 关键操作可读且流程通过，不等于所有比例都理想。
- 实体手机和普通设备性能未测。软件渲染 CI 的低帧率与长测试耗时不能作为真机性能结论，也不能宣称达到 30 FPS。
- v9 官方部署成功、67项构建包内逐项一致，live入口JS/CSS匹配；云WebGL创建失败，入口核验不等于线上3D或真机体验。当前身份见CURRENT_STATE。
- 摄影 PNG 仅会话内保存，应主动下载；本地进度保存不包含 PNG，存储被拒绝/清理可能丢失进度。
- 平台是原创展示设计，不是校园实测建筑；纸飞机是游戏化运动及点代理碰撞，不是完整机翼物理。

## 本轮设计：连续默认体验（开发中）

用户要求持续优化。本轮将普通玩家路径可见的楼体和地表作为设计单位：虎峪主楼西/北（门侧）墙与迎西长楼西面使用米级成组窗、暗基座、独立顶层节奏，替换而不叠加原窗。新立面是原创设计补全，不改变建筑footprint/估算高度，不覆盖已有GLB，也不宣称具体实名用途。

两条样板地表沿现有虎峪北门内侧→西角→梅花方向、迎西机械馆→清泽园通道补前场/边带/路口收口。保原导航、植物位置/计数与全部实体；宽度/材料为设计近似，官方图仅支持拓扑。地面复用现有三材质合批，立面无新纹理、只共用两种strip材质和原窗口instancing。

默认画质仍auto/clear/smooth，最低auto倍率.5/Basic1024；参考锁档只隔离美术差异。新节奏必须在普通相机实走和低档图上仍可辨，不能靠更多微小线条或只选高清画面宣成功。仍保官方带日期故事、原任务/照片schema、可见来源说明、单目标HUD和理想原创设施。

v9是局部迭代，不是豪华全校园；粗干遮挡、空场、低档模糊/门暗纹与实机性能未验仍需诚实记录。后续按实际新图判断是否有价值，不能用自动测试绿替代用户体验或声称用户已满意。
