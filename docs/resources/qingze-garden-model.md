## 状态与权利

这是用户同意用于**游戏内测试**的原创展示性周边场景，尚未完成最终美术验收。不是清泽园实测布局或百年学坛雕塑复原，不能写成真实园内雕塑、历史或精确坐标。圆庭、花岛、三段弧形坐凳和三株垂枝树均是独立设计的估计。GLB 不包含人物托球/球体雕塑、浮雕、铭文、官方照片、外部模型或贴图；官方照片仅在仓库外观察，图片和雕塑复制权利未经确认。参考来源和像素观察细节见 [qingze-garden-references.md](qingze-garden-references.md)。

背景源占地是 [OpenStreetMap way 343238097](https://www.openstreetmap.org/way/343238097)，保留现有 OSM 贡献者署名/ODbL 说明；数据不是现场测绘。参考照片网页：[学校导览](https://www.tyut.edu.cn/xxgk1/xydl.htm)、[校友办](https://xiaoyou.tyut.edu.cn/info/1078/1810.htm)、[2017 活动报道](https://www.tyut.edu.cn/info/1028/2782.htm)；只借鉴常见曲线铺装、低台地和下垂枝冠的空间关系，未提取照片纹理或复制公共艺术造型。图片公开可见不代表再分发许可。关于导出和释放，本轮核阅 [Three.js GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html) 与 [资源释放指南](https://threejs.org/manual/pages/how-to-dispose-of-objects.html)，2026-10-30。

## 观察与验收界限

建议观察点 `[35,193]`，半径候选 5.5m。目标为中央垂枝树冠，metadata 的 target、四个 focus 点和全景 frame 点均采自实际导出顶点，而非虚构包围盒角点；花草顶点也保留为可选语义样本。`yx-garden-setting` 是模型/摄影主体标识，地图地标仍沿用 `yx-garden`。在一个假设的桌面机位下，朝目标、pitch −0.20 的解析投影落入当前框选范围；这不是实拍或合格证明。照片玩法须在集成后的实际相机、玩家遮挡、画幅、近景物体、路径和触控下重新测试并看图，不以数值/射线测试替代审美验收。

仓库外 `asset-candidates/qingze-setting/` 有独立 Blender 前景、正面、斜视预览；预览中 CC0 Hoodie 人物、地面和灯光在 GLB 导出后加入，不是发布模型组成。太阳方向和暖色接近游戏，但 Blender AgX/世界光并非游戏 ACES/半球光；场景仍偏规则、树冠有低多边形风格，需在游戏中审视。没有实际游戏 FPS、移动设备、行走和碰撞通过的证据，不声称最终质量合格。

生成与验证命令见 `scripts/art/qingze-garden/README.md`。Blender 可重建同一材质及面几何，但三角索引顺序跨运行非字节确定；检查实际发布资产仍以 metadata 的 SHA 为准，另用 oriented triangle/normal/material 比较验证几何一致性。
