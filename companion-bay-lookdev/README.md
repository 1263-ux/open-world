# 云湾同行：独立可执行设计假设

不是新正式章节、不是交付替换、没有部署。原CH01文字和章长未改。目标是测试“玩家通过船的位置与速度，得到小鱼对周围事物的不同回应”，而不是三道旋转锁的通过率。

## 运行与范围
从项目根目录经任意已有静态服务器访问 `companion-bay-lookdev/index.html`，需要WebGL。浏览器依赖只引用现有 `game/vendor/three.module.js`。不引入CDN、付费API、外部图片、音频或保存状态。方向按钮与WASD同控制器，E/折纸按钮在靠近时同动作。拖动转视角，滚轮拉近。稳定game完全未改。

空间：约20×16米浅湾，中间低岛提供左右两条真实可通行弧；左侧雨滴，右侧云形水面色块，北侧固定源/折纸/接水池。水面色块是反光构图占位，不冒充物理反射。雨滴和云不会奖励计数，也不是必点按钮。

伙伴：进入云区快速移动时鱼转向云，减速后短停；雨滴区转向雨滴，离开刺激区低速休息；朝向由目标相对船位置计算，非随时间播放唯一循环。鱼仍在透明舱内，不说人话。没有把停留变成必须善良才能推进的检查。

折纸：自由边沿真实局部X轴折痕下降，固定边不动，不是整个托盘在水平面转90度；现版本一个预设可折动作，不夸称自由布料谜题。连接后可见纸面流动水珠及落水珠，接水池变湿。仅证明空间因果，不包含后续三章、终章剧情或收藏。

## 可重复证据
- `node companion-bay-lookdev/test.mjs`：真实Controller左右弧通行、五种伙伴响应/暂停、近距离折纸、固定折痕/端点位移/刚性长度。
- `node companion-bay-lookdev/export.mjs`：从**同一Three几何与状态**导出cloud/rain/folded三个GLB。FileReader仅为Node导出兼容；导出器来自已安装Three。
- `blender -b -t 2 -P companion-bay-lookdev/render.py`：CPU离线渲染上述GLB，不另起浏览器，不触碰GPU设置。首次启用降噪因本机缺少OpenImageDenoise失败，已关闭降噪，不伪称首轮成功。
- `evidence/tests.json`记录实际数值；PNG为离线场景观察，不是WebGL截图或帧率证据。

## 不能用程序测试证明的核心
鱼现在参与“环境→伙伴回应→玩家注意”的信息链，不只是正弦摆尾。但删掉鱼仍可驾驶和折纸，这是保留无强制陪伴的必要边界。**不能因此宣称已证明有趣或已使鱼不可删除。**应做有鱼/无鱼对照：测试者是否更早转向云影、自愿减速、回看水面，并能复述伙伴反应。若普通镜头下鱼太小，看不见状态区别，逻辑再丰富也无效，应先改可读性而不是加奖励门槛。

离线小鱼近景只是诊断，不是拿特写代替普通游玩镜头。画面仍是原创几何灰模级实验，不宣称已达到核心视觉圣经品质。新增布局、节奏和状态均为Agent设计假设，等待评审。

## 当前动作边界与源水修正
E 仍是船靠近时远程触发折页，没有下船、伸手抓纸或手部接触动画；因此只完成固定铰链几何试验，**未完成真实角色折纸动作**。折叠前已持续显示源水珠沿旧短槽流至折痕、侧漏回原池；折叠后侧漏停止，纸面流水与接收池打开。这个变化是“为什么要折”的可视因果假设，不是已经通过玩家可读性验收。

失焦/隐藏会清空移动键与拖镜头状态并暂停；继续需点击“继续”。暂停期间不能折纸，人物、纸页与伙伴计时均不推进。
